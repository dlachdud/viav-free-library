## 📌 주문 안내문 프롬프트

아래 칸을 채우고 통째로 복사해서 Claude에 붙여 넣으세요 :)

### 1단계 · 빈칸 채우기

- [ ] 가게 이름: \_\_\_
- [ ] 상품 이름과 가격: \_\_\_ (예: 답례떡 10개 세트 \_\_\_원)
- [ ] 최소 주문 수량: \_\_\_
- [ ] 픽업 날짜와 시간: \_\_\_
- [ ] 보관 방법과 드시는 기한: \_\_\_
- [ ] 주문 마감 시간: \_\_\_

### 2단계 · 그대로 붙여 넣는 프롬프트

```javascript
너는 떡케이크·답례떡 공방의 주문 안내문을 쓰는 도우미야.
아래 정보로 손님께 보낼 한 장짜리 주문 안내문 초안을 써 줘.

[가게 이름] ___
[상품과 가격] ___
[최소 주문 수량] ___
[픽업 날짜와 시간] ___
[보관 방법과 드시는 기한] ___
[주문 마감] ___

조건:
- 다정한 존댓말로 써 줘 ("사장님" 말투 말고 손님께 쓰는 말)
- 한 문장은 40자 이내로 짧게
- 제목 → 가격 → 픽업 → 보관 → 주문 방법 순서로 정리해 줘
- 내가 적지 않은 정보는 지어내지 말고 [확인 필요]라고 표시해 줘
```

### 3단계 · 받은 초안 다듬기

```javascript
방금 안내문을 DM으로 보내기 좋게 5줄 이내로 줄여 줘.
그리고 가격과 픽업 날짜가 틀리지 않았는지 내가 적은 정보와 하나씩 비교해 줘.
```

### 마지막 확인 (1분)

- [ ] 가격 숫자가 내가 적은 것과 같은가요?
- [ ] 픽업 날짜·시간이 맞나요?
- [ ] \[확인 필요\] 표시가 남아 있지 않나요?
- [ ] 우리 가게 말투로 한 군데만 고쳐 봤나요?
