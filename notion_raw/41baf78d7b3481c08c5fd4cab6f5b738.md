## 연말 DM 답장 예시 5개

연말엔 비슷한 질문이 한꺼번에 들어오죠. 답장을 미리 만들어 두고, 질문이 오면 복사해서 보내 보세요.

### 1단계 · AI로 우리 가게 답장 만들기

ChatGPT · Gemini 같은 AI에 아래 글을 그대로 붙여 넣고, \[ \] 칸만 우리 가게 내용으로 바꿔 주세요.

```txt
너는 [가게 종류]를 혼자 운영하는 사람의 인스타 DM 답장을 대신 써 주는 도우미야.
아래 정보로 연말에 손님이 자주 묻는 질문 5개와 답장을 만들어 줘.

- 가게 이름: [가게 이름]
- 연말 상품과 가격: [상품 이름 · 가격]
- 예약 마감일: [날짜]
- 픽업 가능한 날과 시간: [요일 · 시간]
- 포장 · 배송: [되는 것 / 안 되는 것]

조건
1. 다정한 존댓말로, 답장마다 3줄 이내
2. 가격 · 날짜 · 시간은 내가 적은 것만 쓰기
3. 모르는 내용은 지어내지 말고 "확인하고 바로 알려 드릴게요"로 쓰기
4. 마지막 줄은 손님이 다음에 할 일(날짜 · 수량 남기기 등)로 끝내기
```

### 2단계 · 바로 쓰는 예시 5개 (쿠키 가게 기준)

\[ \] 칸만 바꾸면 다른 디저트 가게에서도 그대로 쓸 수 있어요.

<b>① 예약 마감을 물을 때</b><br />질문: "크리스마스 쿠키 박스 예약 언제까지예요?"

```txt
안녕하세요 :) 크리스마스 [상품 이름]은 [12월 ○일]까지 예약받고 있어요
픽업은 [12월 ○일~○일, ○시~○시]에 가능해요
원하시는 날짜와 수량을 남겨 주시면 바로 확인해 드릴게요
```

<b>② 가격과 구성을 물을 때</b><br />질문: "쿠키 박스 가격이랑 구성이 어떻게 돼요?"

```txt
[상품 이름]은 [가격]이고, [구성: 쿠키 ○종 ○개]가 들어가요
사진은 프로필 고정 게시물에서 보실 수 있어요
수량이 정해지면 말씀해 주세요 :)
```

<b>③ 선물 포장을 물을 때</b><br />질문: "연말 선물 포장도 되나요?"

```txt
네 선물 포장 가능해요 :)
[포장 종류]로 해 드리고, [추가 비용: 무료 / ○원]이에요
메시지 카드가 필요하시면 넣을 문구도 같이 남겨 주세요
```

<b>④ 당일 구매를 물을 때</b><br />질문: "오늘 가면 바로 살 수 있어요?"

```txt
오늘은 [현장 판매 수량 / 예약분만] 준비돼 있어요
확실하게 받으시려면 예약을 추천드려요
오실 시간을 남겨 주시면 따로 챙겨 둘게요
```

<b>⑤ 단체 · 많은 수량을 물을 때</b><br />질문: "회사 연말 선물로 30개 주문 가능할까요?"

```txt
문의 주셔서 감사해요 :)
[○개] 이상은 [○일 전]까지 주문해 주시면 준비할 수 있어요
받으실 날짜와 원하시는 구성을 알려 주시면 가능 여부를 바로 확인해 드릴게요
```

### 3단계 · 저장해 두고 복사하기

- [ ] 휴대폰 메모에 "연말 답장" 메모를 하나 만들기
- [ ] 위 답장 5개를 붙여 넣고 \[ \] 칸을 우리 가게 내용으로 채우기
- [ ] 가격 · 마감일 · 픽업 시간이 맞는지 한 번 더 보기
- [ ] DM이 오면 메모에서 복사해서 보내기
- [ ] 마감일이 지나면 답장 내용도 바로 고치기
