# VIAV 비아브 홍보 무료자료 (자료실)

- 공개 주소: https://viav-free-library.vercel.app (2026-10-29 Vercel 배포)
- GitHub 저장소: https://github.com/dlachdud/viav-free-library

## 폴더 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 자료실 화면 (처음 화면 → 분야 → 자료) |
| `자료실_설정.json` | 자료실 이름 · 슬로건 · 공개 비율 · 맨 아래 배너 |
| `content/<분야>/_분야.json` | 분야 이름 · 아이콘 · 한 줄 설명 · 순서 |
| `content/<분야>/*.md` | 자료 한 개 = 파일 한 개 |
| `build.js` | 자료를 모아 `assets/data.js` 로 만들어요 |
| `assets/` | 로고 · 색 · 화면 동작 |
| `자료_목록.md` | 어떤 자료를 올릴지 정리한 목록 |

## 자료 추가하는 법
1. 맞는 분야 폴더에 `.md` 파일을 하나 만들어요. 맨 위는 이렇게 시작해요.
   ```
   ---
   제목: 자료 제목
   받는것: 이 자료로 받는 것 한 줄
   날짜: 2026-10-29
   순서: 2
   ---
   ```
2. 본문은 25% 안팎을 공개 부분으로 쓰고, 그 아래에 `<!-- 잠금 -->` 한 줄을 넣어요.
   - 이 줄이 없으면 자동으로 앞 25% 안팎에서 잠가요.
   - 프롬프트와 영상은 늘 잠금 아래로 가요 (공개 부분에 있으면 자동으로 그 앞에서 잠가요).
3. 쓸 수 있는 모양
   - 프롬프트(복사 버튼 생김): ```` ```프롬프트 ```` 로 시작해서 ```` ``` ```` 로 끝내기
   - 영상(바로 재생): `@영상 https://youtu.be/...` 또는 `@영상 https://www.instagram.com/reel/...`
   - 체크리스트 `- [ ] ...`, 표 `| ... |`, 빈칸 강조 `【메뉴】`
4. `node build.js` 를 실행하면 자료실에 반영돼요.

## 이메일 → 스티비 주소록
- 자료 잠금 상자에 이메일 + (필수) 개인정보 동의 + (선택) 광고성 정보 동의를 받아요.
- 화면이 `/api/subscribe` (`api/subscribe.js`, Vercel 서버 함수)로 보내면, 스티비 주소록에 구독자로 넣어요.
  - 주소록 · 분야별 그룹 번호는 `자료실_설정.json` 의 「스티비」 한 곳에 있어요 (주소록 526811 · 릴스 527950 · AI 527951 · 주문 527952).
  - API 키는 Vercel 환경 변수 `STIBEE_API_KEY` 에만 넣어요. 저장소나 채팅에 쓰지 않아요.
  - 이미 구독 중인 이메일은 이번 분야 그룹에만 더해요. 스티비가 실패하거나 늦어도(6초) 방문자에게는 자료가 열려요.
- 한 번 넣으면 같은 브라우저에서는 모든 자료가 계속 열려 있어요. 잠금은 화면에서만 가리는 방식이에요.

## Vercel 배포
- 이 저장소의 `main` 에 올라오면 Vercel 이 `node build.js` 를 실행하고 `dist/` 폴더만 공개해요 (`vercel.json`).
- 그래서 `content` · `tools` · `notion_raw` · `build.js` 는 사이트에 공개되지 않아요. (저장소가 Public 이면 GitHub 에서는 보여요)
- 직접 배포: `./deploy.sh` ("자료실 배포해줘") → 만들어 보고 확인한 뒤 `main` 에 올려요.
- 매일 저녁 8:51 자동 작업도 노션 자료를 옮겨 `main` 에 올려요.
- 처음 화면이 빨리 뜨도록 `assets/data.js` 에는 목록만 넣고, 자료 본문은 `assets/items/<분야>--<자료>.json` 으로 따로 둬서 자료를 열 때만 불러와요.

## 홈페이지에 붙이기 (코드 두 줄)
`홈페이지에_붙이기.html` 의 두 줄을 홈페이지의 HTML 블록에 붙여 넣으면 돼요.
```html
<div id="viav-free-library"></div>
<script src="https://viav-free-library.vercel.app/embed.js" defer></script>
```
- 자료실은 상자 안(Shadow DOM)에 그려져서 홈페이지 디자인과 섞이지 않아요.
- 자료를 열면 홈페이지 주소 끝에 `#/ai/...` 같은 표시가 붙어요 (그 주소를 공유하면 그 자료가 바로 열려요).
- 이메일 · 스티비 연결도 그대로 돼요.

## 노션에서 자료 옮기기 (tools/notion_import.py)
1. 노션 「DM 자료 모음」의 하위 페이지를 읽어 `notion_raw/_pages.json`(아이콘 · 날짜 · 웹 게시)과 `notion_raw/<페이지 id>.md`(노션 원문 그대로)로 저장해요. (지금은 Claude 가 노션 연결로 읽어 저장해요. 다음 단계의 매일 자동 반영도 이 방식)
2. 새 페이지라면 `tools/notion_import_map.json` 에 분야 · 주소 이름(영어·숫자) · 받는 것 · 한 줄 소개를 적어요.
3. `python3 tools/notion_import.py` → `node build.js`. 결과는 `tools/last_import.md` 에 표로 남아요.
- 비아브 로고 아이콘인 페이지만 옮겨요. 🔴 · 웹 게시 꺼짐(web_published: false) · 템플릿 페이지는 건너뛰어요.
- 배너 · 인스타 바로가기 · 템플릿 소식 문구 · 회색 확인 메모 · 날짜 지난 행사 안내는 빼요.
- 이 도구가 만든 파일(맨 위 `노션:` 줄)만 다시 만들어요. 손으로 쓴 자료는 그대로 둬요.

## 매일 동기화 (tools/sync.py, 새벽 5:53)
- 예약 작업 「자료실 매일 반영」이 매일 새벽 5:53(한국 시간)에 노션 「DM 자료 모음」을 다시 읽어 `notion_raw/` 를 고친 뒤 `python3 tools/sync.py` 를 돌려요.
- 지난번에 올린 목록(`tools/sync_state.json`)과 비교해서 새 자료 · 바뀐 자료 · 내린 자료를 찾고, 바뀐 게 있을 때만 `./deploy.sh` 로 올려요.
  - 새 자료: 비아브 로고 아이콘으로 바뀐 자료. 분야는 제목으로 정하고, 애매하면 "확인 필요" 로 남겨요.
  - 내린 자료: 🔴 로 바뀐 자료 · 웹 게시 꺼짐(`web_published: false`) · 노션에서 빠진 자료. 노션 원문은 지우지 않아요.
- 결과는 `tools/sync.log` 에 하루 한 줄: `2026-10-31 05:53 · 새 자료 1 · 바뀐 자료 0 · 내린 자료 0 · 올림 ✓ · 확인 필요: 없음`
- 미리 보기만: `python3 tools/sync.py --dry-run`

## 나만 보는 관리자 페이지

- 화면: `admin.html` (자료 목록 · DM 링크 복사 · 새벽 반영 기록 · 스티비 주소록 바로가기)
- `node build.js` 가 `dist/<관리자 주소>/index.html` 로 만들어요. 자료실을 다시 올릴 때마다 같이 새로 만들어져요.
- 관리자 주소는 저장소가 공개라서 여기 적지 않아요. Vercel 환경 변수 `VIAV_ADMIN_PATH` 에만 있어요 (`kanri-` + 영어 소문자·숫자 16자 이상). 값이 없으면 관리자 페이지를 만들지 않아요.
- 검색엔진 막기: 페이지 안 `noindex` 표시 + `vercel.json` 의 `X-Robots-Tag` · `Referrer-Policy: no-referrer` (다른 사이트로 넘어갈 때 주소를 알리지 않아요).
- DM 링크 앞부분은 `자료실_설정.json` 의 `자료실주소` 예요. 홈페이지 주소로 바꾸면 다음 배포부터 바뀌어요.
