# VIAV 비아브 홍보 무료자료 (자료실)

- 공개 주소: https://viav-free-library.vercel.app (2026-10-29 Vercel 배포)
- GitHub 저장소: https://github.com/dlachdud/viav-free-library

## 폴더 구성
| 파일 | 하는 일 |
|---|---|
| `index.html` | 자료실 화면 (처음 화면 → 분야 → 자료) |
| `자료실_설정.json` | 자료실 이름 · 슬로건 · 공개 비율 · 맨 아래 배너 |
| `content/<분야>/_분야.json` | 분야 이름 · 아이콘 · 한 줄 설명 · 순서 |
| `content/<분야>/*.md` | 자료 한 개 = 파일 한 개 |
| `build.js` | 자료를 모아 `assets/data.js` 로 만들어요 |
| `assets/` | 로고 · 색 · 화면 동작 |
| `자료_목록.md` | 어떤 자료를 올릴지 정리한 목록 |

## 자료 추가하는 법
1. 맞는 분야 폴더에 `.md` 파일을 하나 만들어요. 맨 위는 이렇게 시작해요.
   ```
   ---
   제목: 자료 제목
   받는것: 이 자료로 받는 것 한 줄
   날짜: 2026-10-29
   순서: 2
   ---
   ```
2. 본문은 25% 안팎을 공개 부분으로 쓰고, 그 아래에 `<!-- 잠금 -->` 한 줄을 넣어요.
   - 이 줄이 없으면 자동으로 앞 25% 안팎에서 잠가요.
   - 프롬프트와 영상은 늘 잠금 아래로 가요 (공개 부분에 있으면 자동으로 그 앞에서 잠가요).
3. 쓸 수 있는 모양
   - 프롬프트(복사 버튼 생김): ```` ```프롬프트 ```` 로 시작해서 ```` ``` ```` 로 끝내기
   - 영상(바로 재생): `@영상 https://youtu.be/...` 또는 `@영상 https://www.instagram.com/reel/...`
   - 체크리스트 `- [ ] ...`, 표 `| ... |`, 빈칸 강조 `【메뉴】`
4. `node build.js` 를 실행하면 자료실에 반영돼요.

## 이메일
- 지금은 이메일을 넣으면 그 브라우저에서 모든 자료가 열리기만 해요. 어디에도 보내거나 저장하지 않아요.
- 이메일 서비스를 연결할 때는 `assets/app.js` 의 `sendEmail` 함수만 바꾸면 돼요.
- 잠금은 화면에서만 가리는 방식이라, 마음먹고 파일을 열어 보면 내용이 보일 수 있어요. 무료 자료용으로는 충분해요.

## Vercel 배포
- 이 저장소의 `main` 에 올라오면 Vercel 이 `node build.js` 를 실행하고 `dist/` 폴더만 공개해요 (`vercel.json`).
- 그래서 `content` · `tools` · `notion_raw` · `build.js` 는 사이트에 공개되지 않아요. (저장소가 Public 이면 GitHub 에서는 보여요)
- 압축 파일을 끌어다 놓을 필요가 없어요. 매일 저녁 자동 작업이 노션 자료를 옮겨 `main` 에 올려요.

## 노션에서 자료 옮기기 (tools/notion_import.py)
1. 노션 「DM 자료 모음」의 하위 페이지를 읽어 `notion_raw/_pages.json`(아이콘 · 날짜 · 웹 게시)과 `notion_raw/<페이지 id>.md`(노션 원문 그대로)로 저장해요. (지금은 Claude 가 노션 연결로 읽어 저장해요. 다음 단계의 매일 자동 반영도 이 방식)
2. 새 페이지라면 `tools/notion_import_map.json` 에 분야 · 주소 이름(영어·숫자) · 받는 것 · 한 줄 소개를 적어요.
3. `python3 tools/notion_import.py` → `node build.js`. 결과는 `tools/last_import.md` 에 표로 남아요.
- 비아브 로고 아이콘인 페이지만 옮겨요. 🔴 · 웹 게시 꺼짐(web_published: false) · 템플릿 페이지는 건너뛰어요.
- 배너 · 인스타 바로가기 · 템플릿 소식 문구 · 회색 확인 메모 · 날짜 지난 행사 안내는 빼요.
- 이 도구가 만든 파일(맨 위 `노션:` 줄)만 다시 만들어요. 손으로 쓴 자료는 그대로 둬요.
